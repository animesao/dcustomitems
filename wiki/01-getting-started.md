# 01. Установка

> **Что ты узнаешь:** какие требования нужны, как поставить плагин, что должно
> появиться на сервере и как убедиться, что всё работает.
>
> **Предусловия:** сервер на Paper или Spigot, версия Minecraft **1.21.8+**.

## Требования

| Что | Версия | Обязательно? |
|-----|--------|--------------|
| Minecraft | 1.21.8 или новее | да |
| Сервер | Paper (рекомендуется) или Spigot | да |
| Java | **21** или новее | да |
| JDK на сервере | 21+ | только если используете Java-предметы |
| PlaceholderAPI | 2.11+ | нет |
| Vault + плагин экономики | — | нет |

**Paper лучше Spigot**: на нём корректно работают отмена событий, пагинация
инвентаря и часть эффектов. Минимум — Java 21.

### Нужен ли JDK, а не JRE?

Это важно. Плагин **компилирует `.java`-файлы из `items/` прямо на сервере**
(см. [Предметы (Java)](04-java-items.md)). Для этого нужен
**компилятор `javac`**, а он есть только в **JDK**. На «обычной» JRE его нет.

| Что на сервере | Java-предметы |
|----------------|---------------|
| JRE (JRE 21) | ❌ ошибка `JavaCompiler not found` |
| JDK 21+ | ✅ работают |

YAML-предметы, модули-папки и всё остальное работают и на JRE.

**Как проверить, что JDK есть:**

```bash
java -version      # должно быть "OpenJDK ... 21" или новее
javac -version     # если команда есть — это JDK
```

Если `javac` не найден — либо поставьте JDK, либо выключите Java-компиляцию
в `config.yml`:

```yaml
java-compilation: false
```

Подробнее про безопасность — в [Конфигурации](14-configuration.md).

## Установка

**Шаг 1. Скачайте jar.**
Откройте [Releases](https://github.com/animesao/dcustomitems/releases) и
скачайте последний `DC-CustomItems-<версия>.jar`.

**Шаг 2. Положите его в `plugins/`.**

```
/path/to/server/plugins/DC-CustomItems-1.333.0.jar
```

**Шаг 3. Перезапустите сервер.**

**Шаг 4. Проверьте консоль.** Должно быть примерно так:

```
[DC-CustomItems] CustomItems starting...
[Config] Created default messages.java
[CustomItems] Loaded 0 custom items
[JavaCompiler] Compiled: 1, Skipped: 0 (0ms)
[API] Loaded: 0 items, 0 commands, 0 placeholders, 0 modules
[Messages] items/messages.java applied (runtime load())
[DC-CustomItems] CustomItems enabled!
```

Строка `Compiled: 1` — это и есть ваш единственный файл `messages.java`.
Ноль предметов — нормально: вы ещё ничего не создали.

## Что должно появиться на сервере

```
plugins/DC-CustomItems/
├── config.yml            # настройки плагина
├── items/                # ваш контент
│   └── messages.java     # все тексты плагина
├── cache/                # кэш компиляции (не трогайте)
├── compiled/             # скомпилированные .class (не трогайте)
├── data.db               # база SQLite
└── logs/                 # логи, если включён file-logging
```

**Плагин создаёт ровно ОДИН файл** — `items/messages.java`. Никаких
«образцов» в `items/` не появляется: все примеры лежат в репозитории
([`samples/`](https://github.com/animesao/dcustomitems/tree/main/samples))
и копируются вручную, когда понадобятся.

Это сделано намеренно: новичок не должен получать 90 файлов, о которых он
ничего не знает.

## Проверка: всё ли работает

**1. Команда `/ci` отвечает.**

В чате напишите:

```
/ci
```

Должно прийти:

```
=== DC-CustomItems ===
/ci reload - Reload the plugin
```

Если пишет «нет прав» — вы не оператор. Выдайте право (см. [Права](15-permissions.md)).

**2. Создайте первый предмет.**

Откройте `plugins/DC-CustomItems/items/` и создайте файл `test-sword.yml`:

```yaml
test-sword:
  type: TOOL
  activation-slot: HAND
  item:
    type: DIAMOND_SWORD
    title: '&bТестовый меч'
    lore:
      - '&7Просто проверка'
  effects:
    - 'SPEED:1'
```

**3. Перезагрузите.**

```
/ci reload
```

В консоли должно появиться:

```
[items] Loaded item 'test-sword' from test-sword.yml
```

**4. Проверьте в игре.**

Возьмите предмет командой (если у вас есть такая команда) или выдайте его
через любой сторонний плагин. Должно работать:

- у меча есть имя «Тестовый меч» и одна строка лора;
- когда меч в руке, вы получаете эффект Скорость I;
- если убрать меч из руки — эффект пропадает.

**5. Проверьте, что предмет виден плагину:**

```
/ci debug test-sword
```

Покажет `type=TOOL slot=HAND`, материал, количество использований, кулдаун и
ключи PDC — то есть то, что плагин реально прочитал из файла.

Если предмета нет в выдаче — читайте [Решение проблем](17-troubleshooting.md).

## Нужен ли JDK

Коротко: **нужен, если вы пишете предметы/команды/модули на Java.**

Подробно — в разделе [Нужен ли JDK, а не JRE](#нужен-ли-jdk-а-не-jre).

Если сервер запускается в Docker-образе без JDK, добавьте JDK в образ:

```dockerfile
FROM eclipse-temurin:21-jdk
```

## Обновление плагина

1. `/ci backup` — резервная копия `items/`, `config.yml` и `data.db`.
2. Остановите сервер.
3. Замените старый jar новым (удалите старый файл, положите новый).
4. Запустите сервер.

**Что не ломается при обновлении:**

- ваши файлы в `items/` остаются нетронутыми;
- `items/messages.java` остаётся вашим (плагин перезаписывает его только
  если файла нет);
- `config.yml` не перезаписывается — новые ключи появляются в
  дефолтных значениях.

**Что стоит проверить после обновления:**

```bash
# что новые ключи появились (в старом config.yml их не будет)
grep -E "file-logging|backup" plugins/DC-CustomItems/config.yml
```

Отсутствие ключа — не ошибка: плагин использует значение по умолчанию.
Но если хотите настроить — допишите ключ вручную.

## Откат на предыдущую версию

1. Остановите сервер.
2. Верните старый jar.
3. Верните `items/` и `config.yml` из бэкапа, если меняли их.

**Важно:** если вы на 1.333.0 и уходите на 1.332.0 — в `items/messages.java`
могут остаться поля, которых нет в старой версии (`ITEM_EXPIRED`,
`COMMAND_NOT_FOUND` и т.д.). Старая версия их просто не использует, но при
компиляции файла будет ошибка `cannot find symbol` — и сообщения не применятся.
Проверьте консоль после старта.

---

## Удаление

1. `/ci backup` (если хотите сохранить контент).
2. Остановите сервер.
3. Удалите `plugins/DC-CustomItems-*.jar`.
4. Удалите папку `plugins/DC-CustomItems/` — **если не хотите её сохранить**.

При удалении плагина с работающего сервера (без рестарта) из инвентарей
могут остаться «пустые» предметы с PDC-метками. Это нормально: при
следующем запуске сервера они исчезнут.

## Что делать, если что-то пошло не так

| Симптом | Что делать |
|---------|-----------|
| Плагин не включается | Читайте [Решение проблем](17-troubleshooting.md) → «Плагин не включается» |
| `JavaCompiler not found` | Нужен JDK, а не JRE — [см. выше](#нужен-ли-jdk-а-не-jre) |
| `/ci` не отвечает | Нет права `dcustomitems.reload` — [Права](15-permissions.md) |
| Предмет не появляется в игре | `/ci reload`, затем `/ci debug <id>` |
| Ошибки в консоли при старте | Скопируйте их — почти всегда это опечатка в YAML |

Полный список — [Решение проблем](17-troubleshooting.md).
