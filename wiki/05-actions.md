# 05 — Действия

## Что ты узнаешь

- Что такое **действие** (*action*) и в каких местах предмета оно записывается.
- Общий синтаксис строки: `действие:значение` и `действие:арг1:арг2`.
- Полный справочник всех 54 действий: что делает, какие параметры принимает, какие значения по умолчанию.
- Какие действия работают по предмету в слоте активации, а какие — по окружающим сущностям (мобам и игрокам рядом).
- Псевдо-действие `cooldown:MS` — как поставить задержку между срабатываниями.
- Готовые связки: огненный меч, свиток телепортации, аптечка, «прыгающая» обувь.

- Плагин DC-CustomItems установлен, сервер запущен. Порядок установки — [Установка](01-getting-started.md).

- Ты понимаешь, что такое «слот активации» — это объяснено в [Как это работает](02-how-it-works.md).
- Общий список страниц — [оглавление](README.md).

## Что такое действие

**Действие** — это одна команда, которую плагин выполняет в момент срабатывания предмета. Например: показать сообщение, вылечить игрока, ударить всех вокруг, выдать алмаз.

Действия — это «буквы» языка предмета. Сам предмет состоит из статичной части (`item`, `effects`, `attributes` — как он выглядит и что даёт постоянно) и динамичной части (действия — что происходит, когда игрок нажимает кнопку).

## Где используются действия

Три места в YAML-файле предмета:

```yaml
my-item:
  # 1. Клик левой кнопкой мыши
  left-click-actions:
    - 'damage_nearby:10:3'

  # 2. Клик правой кнопкой мыши
  right-click-actions:
    - 'effect:STRENGTH:10:2'

  # 3. Триггеры — реакции на события (убийство, прыжок, подбор...)
  triggers:
    on_kill:
      - 'heal:20'
```

Подробно о триггерах — на странице [Триггеры](06-triggers.md).

> В Java API то же самое делается методами `onLeftClick(...)`, `onRightClick(...)`, `onEquip(...)` и т.д. — см. [Предметы (Java)](04-java-items.md).

## Общие правила

### Формат строки

```
действие:значение
действие:аргумент1:аргумент2:аргумент3
```

- Разделитель — двоеточие `:`.
- Пробелы вокруг двоеточий допустимы, но лучше их не ставить.
- Если параметр не указан, срабатывает значение по умолчанию (оно указано в описании каждого действия).

### Регистр и дефисы

**Имя действия нечувствительно к регистру** и **дефис равен подчёркиванию**:

| Запись | Результат |
|--------|-----------|
| `damage_mobs` | ✅ |
| `damage-mobs` | ✅ то же самое |
| `DAMAGE-MOBS` | ✅ то же самое |
| `DaMaGe_MoBs` | ✅ то же самое |

Это касается только **имени действия**. Значения (например `STRENGTH`, `DIAMOND`) пишутся как обычно — в верхнем регистре для эффектов и материалов.

### Плейсхолдер `%player%`

В некоторых действиях (отмечены в таблицах ниже) текст `%player%` заменяется на ник игрока. Если в системе установлен PlaceholderAPI, то в тексте дополнительно работают плейсхолдеры PlaceholderAPI.

### Что происходит при ошибке

Если в действии опечатка (например, неизвестное имя эффекта) — плагин **не падает**: действие просто ничего не делает. Если внутри действия произошло исключение, в консоль пишется предупреждение вида `Error executing action: ...`, а остальные действия предмета продолжают выполняться.

|----------|-----------|--------|
| `message` | Сообщение в чат игроку | `message:&aПривет, %player%!` |
| `title` | Заголовок и подзаголовок по центру экрана | `title:&cУдар!\|&7Бей!\|10\|40\|10` |
| `actionbar` | Текст над панелью быстрого доступа | `actionbar:&bОсталось 3 заряда` |

| `announce` | То же самое, что `broadcast` | `announce:&6Новый рекорд!` |
| `effect` | Зелье на игрока | `effect:SPEED:10:2` |
| `heal` | Лечит самого игрока | `heal:20` |
| `damage` | Наносит урон самому игроку | `damage:5` |
| `damage_nearby` | Урон всем живым рядом (мобы и игроки) | `damage_nearby:20:4` |
| `damage_mobs` | Урон только мобам рядом | `damage_mobs:15:5` |
| `damage_players` | Урон только игрокам рядом | `damage_players:8:4` |
| `heal_nearby` | Лечит игроков рядом (не мобов) | `heal_nearby:10:6` |
| `effect_nearby` | Зелье всем живым рядом | `effect_nearby:SLOWNESS:10:2:5` |
| `effect_nearby_mobs` | Зелье только мобам рядом | `effect_nearby_mobs:POISON:5:1:4` |
| `effect_nearby_players` | Зелье только игрокам рядом | `effect_nearby_players:BLINDNESS:3:1:4` |
| `teleport` | Телепорт в точку | `teleport:100:64:200` |
| `teleport_relative` | Телепорт относительно текущей позиции | `teleport_relative:0:5:0` |
| `give` | Выдаёт предмет (ванильный или свой) | `give:DIAMOND:3` |

| `exp` | Даёт опыт и уровни | `exp:500:2` |

| `fireworks` | Запускает фейерверк | `fireworks:1` |
| `break` | Ломает блок, на который смотрит игрок | `break` или `break:STONE` |
| `sethealth` | Задаёт здоровье | `sethealth:20` |
| `setfood` | Задаёт сытость | `setfood:20` |
| `set_xp` | Задаёт уровень опыта | `set_xp:5` |
| `vanish` | Невидимость | `vanish:30` |
| `glow` | Свечение (видно сквозь стены) | `glow:10` |
| `speed` | Скорость | `speed:30:2` |
| `flight` | Включает/выключает полёт | `flight:true` |
| `knockback` | Отбрасывает всех живых рядом | `knockback:4` |
| `knockback_mobs` | Отбрасывает только мобов | `knockback_mobs:5` |
| `knockback_players` | Отбрасывает только игроков | `knockback_players:3` |
| `launch` | Подбрасывает вверх всех живых рядом | `launch:2.0` |
| `launch_mobs` | Подбрасывает только мобов | `launch_mobs:2.5` |
| `launch_players` | Подбрасывает только игроков | `launch_players:1.5` |
| `stun` | Оглушает (замедление + усталость) | `stun:3:5` |

| `heal_custom` | Лечение игроков рядом с частицами | `heal_custom:15:8:5:8:HEART` |
| `cooldown:MS` | **Псевдо-действие** (только в триггерах) — задержка | `on_kill:cooldown:3000` |

## Подробный разбор

### Общение

#### `message:ТЕКСТ`

Отправляет текст в чат игроку, который инициировал действие.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `ТЕКСТ` | да | — | Текст сообщения |

- Поддерживает `%player%` и цвета `&`.
- Пустая строка — сообщение не отправляется.

```yaml
- 'message:&aЗаряд восстановлен!'
```

#### `title:ЗАГОЛОВОК|ПОДЗАГОЛОВОК|fadeIn|stay|fadeOut`

Показывает крупный заголовок по центру экрана (как при входе на сервер).

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `ЗАГОЛОВОК` | да | — | Крупный текст |
| `ПОДЗАГОЛОВОК` | нет | пусто | Мелкий текст под заголовком |
| `fadeIn` | нет | `10` | Тики появления (20 тиков = 1 секунда) |
| `stay` | нет | `40` | Тиков, сколько заголовок висит на экране |
| `fadeOut` | нет | `10` | Тиков затухания |

- Поддерживает `%player%` и цвета `&`.
- Разделять параметры нужно вертикальной чертой `|`. Старый формат с двоеточиями тоже принимается, но в нём подзаголовок не может содержать `:` — поэтому используйте `|`.

```yaml
- 'title:&c🔥 ОГОНЬ!|&7Враг рядом|10|40|10'
```

#### `actionbar:ТЕКСТ`

Текст над панелью быстрого доступа (слева от хотбара). Если клиент не поддерживает эту строку, текст просто придёт в чат.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `ТЕКСТ` | да | — | Текст над хотбаром |

```yaml
- 'actionbar:&bЗарядов: 3'
```

#### `broadcast:ТЕКСТ` и `announce:ТЕКСТ`

Отправляет текст **всем игрокам онлайн**. Это два названия одного и того же действия.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `ТЕКСТ` | да | — | Текст объявления |

- `%player%` здесь **не подставляется** — текст уходит всем одинаковым.
- Цвета `&` работают.

```yaml
- 'broadcast:&6Игрок &e%player% &6включил алтарь огня!'
```

### Эффекты и лечение

#### `effect:ТИП:СЕКУНДЫ:УРОВЕНЬ:AMBIENT:ЧАСТИЦЫ`

Надевает на игрока зелье (эффект статуса).

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `ТИП` | да | — | Имя эффекта (см. список ниже) |
| `СЕКУНДЫ` | да | — | Длительность в секундах |
| `УРОВЕНЬ` | нет | `1` | `1` = I, `2` = II, `3` = III … |
| `AMBIENT` | нет | `true` | `true` — «тихий» эффект: видны только частицы-кружочки |
| `ЧАСТИЦЫ` | нет | `true` | `false` — совсем без частиц |

Список имён эффектов (можно писать и синонимы):

| Основное имя | Синонимы | Что даёт |
|--------------|----------|----------|
| `SPEED` | — | Скорость |
| `SLOWNESS` | `SLOW` | Замедление |
| `HASTE` | — | Ускорение добычи |
| `MINING_FATIGUE` | — | Усталость от добычи |
| `STRENGTH` | `INCREASE_DAMAGE` | Сила (больше урона) |
| `JUMP_BOOST` | `JUMP` | Прыгучесть |
| `NAUSEA` | `CONFUSION` | Тошнота |
| `REGENERATION` | — | Регенерация |
| `RESISTANCE` | `DAMAGE_RESISTANCE` | Сопротивление урону |
| `FIRE_RESISTANCE` | — | Сопротивление огню |
| `WATER_BREATHING` | — | Дыхание под водой |
| `INVISIBILITY` | — | Невидимость |
| `BLINDNESS` | — | Слепота |
| `NIGHT_VISION` | — | Ночное зрение |
| `HEALTH_BOOST` | — | Дополнительное здоровье |
| `ABSORPTION` | — | Золотая оболочка (сердца) |
| `SATURATION` | — | Сытость |
| `GLOWING` | — | Свечение |
| `LEVITATION` | — | Левитация |
| `LUCK` | — | Удача |
| `UNLUCK` | — | Неудача |
| `SLOW_FALLING` | — | Медленное падение |
| `CONDUIT_POWER` | — | Сила кондуита |
| `DOLPHINS_GRACE` | — | Благословение дельфина |
| `BAD_OMEN` | — | Дурное предзнаменование |
| `HERO_OF_THE_VILLAGE` | — | Герой деревни |
| `DARKNESS` | — | Тьма |

```yaml
- 'effect:SPEED:10:2'          # Скорость II на 10 секунд
- 'effect:STRENGTH:5:1:false:true'  # Сила I, без «тихого» режима, с частицами
```

#### `heal:КОЛИЧЕСТВО`

Лечит самого игрока. Больше максимального здоровья не станет.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `КОЛИЧЕСТВО` | нет | `10` | Сколько здоровья прибавить (1 = полное сердце) |

```yaml
- 'heal:20'
```

#### `damage:КОЛИЧЕСТВО`

Наносит урон **самому** игроку. Полезно для «цены» предмета.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `КОЛИЧЕСТВО` | нет | `5` | Сколько урона нанести |

```yaml
- 'damage:3'
```

#### `damage_nearby:УРОН:РАДИУС`

Урон всем живым сущностям в радиусе (мобы **и** игроки). Сам игрок не страдает.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `УРОН` | нет | `5` | Сколько урона каждому |
| `РАДИУС` | нет | `3` | Радиус в блоках (по всем трём осям) |

```yaml
- 'damage_nearby:20:4'
```

#### `damage_mobs:УРОН:РАДИУС`

То же самое, но **только мобы** (зомби, скелеты, криперы и прочие). Игроков не трогает.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `УРОН` | нет | `5` | Сколько урона каждому |
| `РАДИУС` | нет | `3` | Радиус в блоках |

```yaml
- 'damage_mobs:15:5'
```

#### `damage_players:УРОН:РАДИУС`

То же, но **только игроки**.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `УРОН` | нет | `5` | Сколько урона каждому |
| `РАДИУС` | нет | `3` | Радиус в блоках |

```yaml
- 'damage_players:8:4'
```

#### `heal_nearby:КОЛИЧЕСТВО:РАДИУС`

Лечит **игроков** рядом (мобов — нет, сам игрок — нет).

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `КОЛИЧЕСТВО` | нет | `10` | Сколько здоровья прибавить каждому |
| `РАДИУС` | нет | `5` | Радиус в блоках |

```yaml
- 'heal_nearby:15:8'
```

#### `effect_nearby:ТИП:СЕКУНДЫ:УРОВЕНЬ:РАДИУС`

Зелье на всех живых рядом (мобы и игроки), кроме самого игрока.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `ТИП` | да | — | Имя эффекта |
| `СЕКУНДЫ` | да | — | Длительность в секундах |
| `УРОВЕНЬ` | да | — | `1` = I, `2` = II … |
| `РАДИУС` | нет | `4` | Радиус в блоках |

- Первые три параметра обязательны: если их меньше, действие не делает ничего.
- Зелье всегда накладывается «обычным» способом (без тихого режима и без частиц).

```yaml
- 'effect_nearby:SLOWNESS:10:2:5'
```

#### `effect_nearby_mobs:ТИП:СЕКУНДЫ:УРОВЕНЬ:РАДИУС`

То же, но **только мобы**.

#### `effect_nearby_players:ТИП:СЕКУНДЫ:УРОВЕНЬ:РАДИУС`

То же, но **только игроки**.

```yaml
- 'effect_nearby_mobs:POISON:5:1:4'
- 'effect_nearby_players:BLINDNESS:3:1:4'
```

### Телепортация

#### `teleport:X:Y:Z[:YAW]`

Телепортирует игрока в указанную точку (в том же мире, где он сейчас).

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `X` | да | — | Координата X |
| `Y` | да | — | Координата Y (высота) |
| `Z` | да | — | Координата Z |
| `YAW` | нет | текущий | Направление взгляда по горизонтали (градусы) |

**Относительные координаты.** Если координата начинается с `~`, она считается от текущей позиции:

| Запись | Смысл |
|--------|-------|
| `~` | Текущая координата (ничего не менять) |
| `~5` | Текущая + 5 блоков |
| `~-5` | Текущая − 5 блоков |
| `100` | Абсолютные 100 блоков |

```yaml
- 'teleport:100:64:200'   # В конкретную точку
- 'teleport:~:5:~'        # На 5 блоков вверх, координаты X и Z не меняются
```

#### `teleport_relative:X:Y:Z`

Сдвигает игрока относительно текущей позиции. Здесь координаты **всегда** прибавляются, даже без `~`.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `X` | нет | `0` | На сколько блоков по X |
| `Y` | нет | `0` | На сколько блоков по Y |
| `Z` | нет | `0` | На сколько блоков по Z |

```yaml
- 'teleport_relative:0:5:0'   # Подбросить на 5 блоков вверх
```

### Выдача предметов

#### `give:МАТЕРИАЛ:КОЛИЧЕСТВО`

Выдаёт предмет в инвентарь игрока. Если инвентарь полон, остаток падает на землю под ногами.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `МАТЕРИАЛ` | да | — | `DIAMOND`, `GOLDEN_APPLE`… **или** id своего предмета |
| `КОЛИЧЕСТВО` | нет | `1` | Сколько выдать (от 1 до 64) |

- Название материала нечувствительно к регистру, можно писать `diamond`, `DIAMOND` или `minecraft:diamond`.
- Вместо материала можно указать **id другого предмета из YAML** — он будет выдан со всеми своими эффектами и действиями.

```yaml
- 'give:DIAMOND:3'
- 'give:vampire-blade:1'
```

#### `remove:МАТЕРИАЛ:КОЛИЧЕСТВО`

Забирает предмет из инвентаря игрока (из любого слота).

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `МАТЕРИАЛ` | да | — | Только ванильный материал |
| `КОЛИЧЕСТВО` | нет | `1` | Сколько забрать |

- Работает **только** с обычными материалами; свой предмет так забрать нельзя.
- Если предмета меньше, чем указано — заберётся сколько есть.

```yaml
- 'remove:COAL:10'
```

#### `exp:ОПЫТ[:УРОВНИ]`

Даёт игроку опыт (очки опыта) и/или уровни.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `ОПЫТ` | нет | `100` | Очки опыта |
| `УРОВНИ` | нет | `0` | Сколько уровней добавить |

```yaml
- 'exp:500:2'   # 500 очков опыта и 2 уровня
```

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `ТИП` | да | — | Имя частицы: `FLAME`, `HEART`, `PORTAL`… |
| `КОЛИЧЕСТВО` | нет | `10` | Сколько частиц |

Проигрывает звук игроку.

| Параметр | Обязательный | По умолчанию | Значение |

| `ТОН` | нет | `1.0` | Высота тона: `0.5` — ниже, `2.0` — выше |

#### `fireworks:ЗНАЧЕНИЕ`

Запускает над игроком фейерверк (красный с оранжевым, с мерцанием и следом). Параметр не влияет на результат — он есть только для единообразия.

```yaml
- 'fireworks:1'
```

#### `break[:МАТЕРИАЛ]`

Ломает блок, на который игрок смотрит. Расстояние — до 5 блоков.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `МАТЕРИАЛ` | нет | любой | Ломать только блок этого типа |

- Если блока нет или он слишком далеко — ничего не происходит.
- Блок ломается «естественным» способом: с выпадением ресурсов и правилами защиты территории.

```yaml
- 'break'          # Сломать любой блок, на который смотришь
- 'break:STONE'    # Только камень
```

### Состояние игрока

#### `sethealth:ЗНАЧЕНИЕ`

Задаёт здоровье игрока точно (не лечит, а устанавливает).

### Команды

#### `command:КОМАНДА`

Выполняет команду **от имени консоли** (не от игрока — права игрока не учитываются).

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `КОМАНДА` | да | — | Текст команды без ведущего слэша |

- `%player%` подставляется — ник игрока.
- Так как команда идёт от консоли, у неё есть права оператора. Это мощный инструмент: пользуйтесь аккуратно.

```yaml
- 'command:give %player% diamond 1'
- 'command:execute at %player% run tp %player% @a[sort=random,limit=1,distance=1..]'
```

#### `console_command:КОМАНДА`

То же самое, но **без** подстановки `%player%`.

```yaml
- 'console_command:say Сервер запущен'
```

### Продвинутые действия

Эти действия умеют больше, чем остальные: у них есть координаты, задержки, точные размеры области.

#### `particles_custom:ТИП:КОЛИЧЕСТВО:X:Y:Z:OFF_X:OFF_Y:OFF_Z`

Частицы с точным смещением и разбросом.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `ТИП` | да | — | Имя частицы |
| `КОЛИЧЕСТВО` | нет | `10` | Сколько частиц |
| `X` | нет | `0` | Смещение точки по X от игрока |
| `Y` | нет | `1` | Смещение по Y (по умолчанию — на уровне головы) |
| `Z` | нет | `0` | Смещение по Z |
| `OFF_X` | нет | `0.5` | Разброс частиц по X |
| `OFF_Y` | нет | `0.5` | Разброс частиц по Y |
| `OFF_Z` | нет | `0.5` | Разброс частиц по Z |

```yaml
- 'particles_custom:FLAME:200:0:1:0:3:1:3'   # Огненное кольцо
- 'particles_custom:DRAGON_BREATH:100:0:2:0:2:2:2'
```

#### `sound_sequence:ЗВУК1:ГРОМКОСТЬ1:ТОН1;ЗВУК2:...`

Несколько звуков подряд. Разделитель — точка с запятой `;`.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `ЗВУК` | да | — | Имя звука |
| `ГРОМКОСТЬ` | нет | `1.0` | Громкость |
| `ТОН` | нет | `1.0` | Тон |

- Все звуки проигрываются **одновременно**. Задержек здесь нет.

```yaml
- 'sound_sequence:ENTITY_BLAZE_SHOOT:1:1;ENTITY_GENERIC_EXPLODE:1:0.8'
```

#### `title_sequence:ЗАГОЛОВОК|ПОДЗАГОЛОВОК|FADEIN|STAY|FADEOUT;...`

Несколько заголовков подряд. Разделитель — `;`. Формат каждого заголовка — такой же, как у `title`.

- Все заголовки показываются **одновременно** (последний перезаписывает предыдущий), задержек нет.

```yaml
- 'title_sequence:🔥 ПОДГОТОВКА!:::10:20:10;🔥 ОГОНЬ!:::10:30:10;🔥 ГРОЗА!:::10:40:10'
```

#### `command_sequence:КОМАНДА1:ЗАДЕРЖКА1;КОМАНДА2:ЗАДЕРЖКА2;...`

Несколько команд, выполняемых **с задержками**. Разделитель — `;`.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `КОМАНДА` | да | — | Текст команды (без слэша) |
| `ЗАДЕРЖКА` | нет | `0` | Задержка **в миллисекундах** до следующей команды |

- Команды выполняются от консоли, `%player%` подставляется.
- Задержки **складываются**: вторая команда стартует через `ЗАДЕРЖКА1 + ЗАДЕРЖКА2` миллисекунд после начала.
- Минимальный шаг — 1 тик (50 мс), то есть задержка `0` всё равно даёт паузу в один тик.

```yaml
# Награда в три шага: сразу, через 0.5 с и ещё через 0.5 с
- 'command_sequence:give %player% diamond 5:500;give %player% emerald 3:500;say Готово!:500'
```

#### `teleport_sequence:X1:Y1:Z1:ЗАДЕРЖКА1;X2:Y2:Z2:ЗАДЕРЖКА2;...`

Несколько телепортов подряд с задержками. Разделитель — `;`.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `X`, `Y`, `Z` | да | — | Абсолютные координаты точки |
| `ЗАДЕРЖКА` | нет | `0` | Задержка **в миллисекундах** до следующего телепорта |

- Задержки складываются.
- Точка должна содержать хотя бы три координаты, иначе она пропускается.

```yaml
- 'teleport_sequence:100:64:200:500;200:64:300:500;300:64:400'
```

#### `effect_sequence:ТИП1:СЕКУНДЫ1:УРОВЕНЬ1:ЗАДЕРЖКА1;...`

Несколько зелий с задержками. Разделитель — `;`.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `ТИП` | да | — | Имя эффекта |
| `СЕКУНДЫ` | да | — | Длительность в секундах |
| `УРОВЕНЬ` | нет | `1` | `1` = I, `2` = II … |
| `ЗАДЕРЖКА` | нет | `0` | Задержка **в миллисекундах** до следующего зелья |

- Задержки складываются.
- Нужны хотя бы два параметра (тип и длительность), иначе запись пропускается.

```yaml
- 'effect_sequence:SPEED:10:2:0;STRENGTH:10:3:1000;FIRE_RESISTANCE:10:1:2000'
```

#### `damage_custom:УРОН:ШИРИНА:ВЫСОТА:ГЛУБИНА`

Урон по области с точным размером (прямоугольник, а не куб).

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `УРОН` | нет | `5.0` | Сколько урона каждому |
| `ШИРИНА` | нет | `3.0` | Размер по X |
| `ВЫСОТА` | нет | `3.0` | Размер по Y |
| `ГЛУБИНА` | нет | `3.0` | Размер по Z |

- Страдает всё живое в области: и мобы, и игроки (кроме самого игрока).

```yaml
- 'damage_custom:30:6:4:6'   # 30 урона в области 6×4×6 блоков
```

#### `heal_custom:ЛЕЧЕНИЕ:ШИРИНА:ВЫСОТА:ГЛУБИНА[:ЧАСТИЦЫ]`

Лечит игроков в области и показывает над ними частицы.

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `ЛЕЧЕНИЕ` | нет | `10.0` | Сколько здоровья прибавить |
| `ШИРИНА` | нет | `5.0` | Размер по X |
| `ВЫСОТА` | нет | `5.0` | Размер по Y |
| `ГЛУБИНА` | нет | `5.0` | Размер по Z |
| `ЧАСТИЦЫ` | нет | `HEART` | Название частицы |

- Лечатся только игроки (мобы — нет, сам игрок — нет).

```yaml
- 'heal_custom:15:8:5:8:HEART'
- 'heal_custom:20:10:8:10:VILLAGER_HAPPY'
```

## Псевдо-действие cooldown

`cooldown:MS` — **не обычное действие**. Оно ничего не делает само по себе, а только ставит задержку: пока она активна, тот же триггер не срабатывает.

Оно работает **только внутри триггеров** (в `triggers:`), а не в `left-click-actions` / `right-click-actions`.

```yaml
my-item:
  triggers:
    on_kill:
      - 'cooldown:3000'      # следующий on_kill — не раньше чем через 3 секунды
      - 'heal:20'
```

Подробности:

| Параметр | Обязательный | По умолчанию | Значение |
|----------|--------------|--------------|---------|
| `MS` | да | `3000` | Задержка в миллисекундах |

- Формат в триггере: `имя_триггера:cooldown:3000`.
- Если в одном триггере несколько `cooldown`, побеждает **наибольшее** значение.
- Задержка относится только к тому триггеру, в котором она указана. `on_kill` с `cooldown:5000` не мешает `on_click_right`.
- Задержка считается для пары «игрок + предмет + триггер»: у другого игрока своя.
- `cooldown` можно поставить **в любое место** списка — он обрабатывается отдельно и не мешает следующим действиям.
- Действие `cooldown:MS` никогда не попадает в `ActionParser`, поэтому обычный парсер его не знает.

Отдельно про `click-cooldown` — общую задержку клика у предмета — читайте в [Триггеры → Задержки](06-triggers.md#задержки).

## Слот активации и область действия

Не каждое действие требует, чтобы предмет лежал в слоте активации. Вот точные правила:

| Ситуация | Где должен быть предмет | Примечание |
|-----------|--------------------------|------------|
| `on_equip` / `on_unequip` | В слоте активации (`activation-slot`) | `HAND`, `OFFHAND`, `HEAD`, `CHEST`, `LEGS`, `FEET` |
| `on_click_left` / `on_click_right` | В той руке, которой кликнули | Слот активации не важен |
| `on_kill`, `on_death`, `on_damage_taken`, `on_damage_dealt`, `on_jump`, `on_sprint` | В руке, во второй руке **или** в любом из 4 слотов брони | Слот активации не важен |
| `on_pickup` / `on_drop` | Предмет поднимается / выбрасывается | Слот не важен вовсе |
| Постоянные `effects` и `attributes` | Только в слоте активации | Иначе эффект не работает |

Какие действия работают по окружающим сущностям:

| Действие | Кого затрагивает |
|----------|------------------|
| `damage_nearby`, `damage_custom` | Все живые рядом: мобы **и** игроки (сам игрок — нет) |
| `damage_mobs` | Только мобы |
| `damage_players` | Только игроки |
| `heal_nearby`, `heal_custom` | Только игроки (мобы и сам игрок — нет) |
| `effect_nearby` | Все живые рядом |
| `effect_nearby_mobs` | Только мобы |
| `effect_nearby_players` | Только игроки |
| `knockback`, `launch`, `stun` | Все живые рядом |
| `knockback_mobs`, `launch_mobs`, `stun_mobs` | Только мобы |
| `knockback_players`, `launch_players`, `stun_players` | Только игроки |
| `give`, `remove`, `exp`, `effect`, `heal`, `damage`, `sethealth`, `setfood`, `set_xp`, `vanish`, `glow`, `speed`, `flight`, `teleport*`, `lightning*`, `particles*`, `sound*`, `fireworks`, `break`, `message`, `title`, `actionbar`, `broadcast` | Только самого игрока (или всех — но только у `broadcast`) |

## Частые ошибки

| Ошибка | Что будет | Как правильно |
|--------|-----------|---------------|
| `effect:SPeed:10:2` — опечатка в имени эффекта | Ничего не произойдёт, ошибки в консоли не будет | Имена эффектов: `SPEED`, `STRENGTH`, `REGENERATION`… |
| `title:Заголовок:Подзаголовок:10:40:10` — подзаголовок с двоеточием | Значения времени уедут в неверные места | Используйте `\|`: `title:Заголовок\|Подзаголовок\|10\|40\|10` |
| `command:give %player% diamond 1` — забыт слэш | Команда выполнится, но не так, как ожидалось | Слэш не нужен, команда пишется без него |
| `give:my-java-item` — предмет из Java API | Предмет не выдастся | `give` работает только с YAML-предметами и материалами |
| `remove:my-custom-item` | Ничего не удалится | `remove` работает только с ванильными материалами |
| `trail-particles:FLAME:3` внутри `triggers:` | Это не действие, оно не выполнится | След частиц задаётся отдельным ключом `trail-particles:` на верхнем уровне предмета |
| `launch:2` — ожидаете радиус | Радиус всегда 4 блока, настроить нельзя | Используйте `knockback:РАДИУС`, если нужен свой радиус |
| `command_sequence:...:20` — думаете, что это тики | Задержка в миллисекундах | `1000` = 1 секунда |
| Пробел после двоеточия в начале значения | Значение будет считаться с пробела — обычно безвредно, но лучше не рисковать | Пишите без пробелов: `effect:SPEED:10:2` |
