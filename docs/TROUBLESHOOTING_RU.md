# Руководство по Решению Проблем

## 📚 Частые Проблемы и Решения

Это руководство поможет вам решить распространённые проблемы с DC-CustomItems.

---

## 🚀 Проблемы Установки

### Плагин Не Загружается

**Проблема:** Плагин не появляется в `/pl`

**Симптомы:**
- Плагин не в списке
- Команды не работают

**Решения:**

1. **Проверьте Версию Java:**
   ```bash
   java -version
   ```
   Нужна Java 17 или выше.

2. **Проверьте Расположение Файла:**
   ```
   server/plugins/dcustomitems.jar
   ```
   Должен быть в папке `plugins/`.

3. **Проверьте Имя Файла:**
   - Должно быть `dcustomitems.jar`
   - Без пробелов и специальных символов

4. **Проверьте Консоль на Ошибки:**
   Ищите сообщения об ошибках при запуске.

5. **Проверьте Версию Сервера:**
   - Нужен Spigot/Paper 1.20+

---

### Плагин Падает при Загрузке

**Проблема:** Сервер падает при загрузке плагина

**Симптомы:**
- Ошибка в консоли
- Сервер останавливается

**Решения:**

1. **Проверьте Сообщение Об Ошибке:**
   Прочитайте полную ошибку в консоли.

2. **Проверьте Зависимости:**
   Некоторые функции требуют Paper.

3. **Проверьте Версию Плагина:**
   Убедитесь что версия совпадает с сервером.

4. **Тестируйте с Минимальной Настройкой:**
   Временно уберите другие плагины.

---

## 🎯 Проблемы с Предметами

### Предмет Не Появляется

**Проблема:** Предмет не появляется после `/ci give`

**Симптомы:**
- Команда работает, но предмета нет
- Предмет не в инвентаре

**Решения:**

1. **Проверьте ID Предмета:**
   ```bash
   /ci list
   ```
   Убедитесь что предмет существует.

2. **Проверьте Права:**
   ```yaml
   permission: "myplugin.use"
   ```
   Убедитесь что у вас есть право.

3. **Перезагрузите Плагин:**
   ```bash
   /ci reload
   ```

4. **Проверьте YAML Синтаксис:**
   - Правильные отступы
   - Без табуляций (используйте пробелы)
   - Правильные кавычки

5. **Проверьте Консоль:**
   Ищите сообщения об ошибках.

---

### Предмет Не Работает

**Проблема:** Предмет есть, но эффекты не работают

**Симптомы:**
- Предмет в инвентаре
- Нет эффектов при использовании

**Решения:**

1. **Проверьте Слот Активации:**
   ```yaml
   activation-slot: HAND
   ```
   Должен совпадать с тем, где держится предмет.

2. **Проверьте Действия:**
   ```yaml
   trigger-actions:
     - 'on_click_right:message:Привет!'
   ```
   Убедитесь что тип события правильный.

3. **Проверьте Кулдаун:**
   ```yaml
   click-cooldown: 3000
   ```
   Подождите кулдаун или установите 0.

4. **Проверьте Права:**
   Некоторые действия требуют определённых прав.

5. **Тестируйте в Креативе:**
   Сначала попробуйте в креативном режиме.

---

### Эффекты Не Отображаются

**Проблема:** Частицы/эффекты не появляются

**Симптомы:**
- Предмет работает
- Нет визуальных эффектов

**Решения:**

1. **Проверьте Имя Частицы:**
   ```yaml
   - 'on_click_right:particle:FLAME:50'
   ```
   Используйте правильные имена частиц.

2. **Проверьте Настройки Клиента:**
   - Частицы должны быть включены
   - Качество графики важно

3. **Проверьте Расстояние:**
   Эффекты могут не показываться издалека.

4. **Попробуйте Другие Частицы:**
   Попробуйте `FLAME`, `HEART`, `CRIT`.

## 🎨 Проблемы с Ресурс-Паком

### Модель Не Появляется

**Проблема:** Предмет показывает стандартную текстуру

**Симптомы:**
- Предмет работает
- Неправильная текстура

**Решения:**

1. **Проверьте Имя Модели:**
   ```yaml
   item-model: "my_model"
   ```
   Должно совпадать с именем файла.

2. **Проверьте Путь Файла:**
   ```
   assets/minecraft/models/item/my_model.json
   ```

3. **Проверьте pack.mcmeta:**
   ```json
   {
     "pack": {
       "description": "Мой Пак",
       "pack_format": 34
     }
   }
   ```

4. **Проверьте Формат Пака:**
   Должен совпадать с версией сервера.

5. **Перезагрузите Ресурс-Пак:**
   - F3 + T в игре
   - Или перезапустите игру

---

### Текстура Отсутствует

**Проблема:** Фиолетовые/чёрные текстуры

**Симптомы:**
- Неправильные цвета текстур

**Решения:**

1. **Проверьте Существование PNG:**
   ```
   assets/minecraft/textures/item/my_model.png
   ```

2. **Проверьте Имя Файла:**
   Должно совпадать со ссылкой модели.

3. **Проверьте Формат Изображения:**
   - Используйте формат PNG
   - Валидный файл изображения

4. **Проверьте Прозрачность:**
   Альфа-канал может вызывать проблемы.

## ☕ Проблемы с Java API

### Java Предмет Не Компилируется

**Проблема:** .java файл не компилируется

**Симптомы:**
- Ошибка в консоли
- Предмет не загружен

**Решения:**

1. **Проверьте Имя Класса:**
   ```java
   public class MySword extends AbstractCustomItem
   ```
   Должно совпадать с именем файла.

2. **Проверьте Импорты:**
   ```java
   import me.dcplugin.dcustomitems.api.AbstractCustomItem;
   import me.dcplugin.dcustomitems.api.ItemAPI;
   ```

3. **Проверьте Методы:**
   - Должны быть переопределены обязательные методы
   - Правильные сигнатуры методов

4. **Проверьте Синтаксис:**
   - Точки с запятой
   - Фигурные скобки
   - Без опечаток

---

### Java Предмет Не Работает

**Проблема:** Скомпилирован, но не работает

**Симптомы:**
- Предмет появляется
- Нет эффектов

**Решения:**

1. **Проверьте ID Предмета:**
   ```java
   @Override
   public String getId() { return "my_sword"; }
   ```

2. **Проверьте Методы Событий:**
   ```java
   @Override
   public void onRightClick(PlayerInteractEvent event, Player player) {
       // Ваш код
   }
   ```

3. **Проверьте Использование ItemAPI:**
   ```java
   ItemAPI.heal(player, 5);
   ItemAPI.effect(player, PotionEffectType.SPEED, 10, 1);
   ```

4. **Перезагрузите и Проверьте:**
   ```bash
   /ci reload
   /api-item give my_sword
   ```

## 🔧 Проблемы с Командами

### Команда Не Найдена

**Проблема:** Команда не работает

**Симптомы:**
- Сообщение "Неизвестная команда"

**Решения:**

1. **Проверьте Загрузку Плагина:**
   ```bash
   /pl
   ```

2. **Проверьте Написание Команды:**
   ```bash
   /ci give my_sword
   ```

3. **Проверьте Права:**
   ```yaml
   customitems.give: op
   ```

4. **Попробуйте Алиас:**
   ```bash
   /customitems give my_sword
   ```

---

### Нет Прав

**Проблема:** Сообщение "Нет прав"

**Симптомы:**
- Команда заблокирована

**Решения:**

1. **Проверьте Ваши Права:**
   - Нужны OP или конкретное право

2. **Добавьте Право:**
   ```bash
   /op ваше_имя
   ```

3. **Используйте Плагин Прав:**
   - LuckPerms
   - PermissionsEx
   - GroupManager

## 💡 Общие Советы

### Совет 1: Сначала Проверяйте Консоль

Всегда проверяйте консоль сервера на ошибки:
- Сообщения при запуске
- Сообщения об ошибках
- Предупреждения

### Совет 2: Тестируйте Простую Настройку

Начните с минимальной конфигурации:
```yaml
test_item:
  item:
    type: DIAMOND_SWORD
    title: 'Тест'
  trigger-actions:
    - 'on_click_right:message:Привет!'
```

### Совет 3: Перезагружайте После Изменений

Всегда перезагружайте после изменений конфига:
```bash
/ci reload
```

### Совет 4: Проверьте Права Файлов

Убедитесь что файлы доступны для чтения:
```bash
chmod 644 items/*.yml
```

### Совет 5: Делайте Бэкапы

Сохраняйте резервные копии рабочих конфигураций.
