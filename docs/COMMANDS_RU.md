# Справочник Команд

## 📚 Полный Список Команд

Это руководство описывает все доступные команды в DC-CustomItems.

---

## 🎯 Основные Команды

### /ci (customitems)

Основная команда плагина.

**Использование:**
```
/ci <подкоманда> [аргументы]
```

**Алиасы:**
- `/customitems`
- `/ci`

---

## 📝 Команды Предметов

### /give

Выдать предмет (кастомный или ванильный).

**Синтаксис:**
```
/give <id|material> [игрок] [количество]
```

**Параметры:**
| Параметр | Обязательный | Описание |
|----------|--------------|----------|
| id\|material | Да | ID кастомного предмета или имя материала |
| игрок | Нет | Имя игрока (по умолчанию — вы) |
| количество | Нет | 1-64 (по умолчанию 1) |

**Примеры:**
```bash
/give vampire-blade                    # Кастомный предмет себе
/give diamond                          # Алмаз себе
/give minecraft:netherite_sword Steve  # Незеритовый меч игроку
/give cooked_beef 64                   # 64 стейка себе
/give diamond all 16                   # 16 алмазов всем онлайн
/give list                             # Список кастомных предметов
/give materials                        # Все ванильные материалы
/give materials diamond                # Поиск по фильтру
```
| игрок | Нет | Игроку кому выдать (по умолчанию: вы) |

**Примеры:**
```bash
# Выдать предмет себе
/ci give my_sword

# Выдать предмет другому игроку
/ci give my_sword Steve

# Выдать предмет ближайшему игроку
/ci give my_sword @p
```

**Права:**
- `customitems.give` (по умолчанию: op)

---

### /give list

Показать список всех доступных кастомных предметов.

**Синтаксис:**
```
/give list
```

**Примеры:**
```bash
# Показать все предметы
/give list
```

**Вывод:**
```
[DC-CustomItems] Доступные предметы: my_sword, my_armor, fire_sword
```

**Права:**
- `customitems.list` (по умолчанию: true)

---

### /ci reload

Перезагрузить все предметы и конфигурации.

**Синтаксис:**
```
/ci reload
```

**Примеры:**
```bash
# Перезагрузить плагин
/ci reload
```

**Вывод:**
```
[DC-CustomItems] Перезагружено 53 кастомных предметов
[DC-CustomItems] [API] Загружено 2 Java API предмета
```

**Права:**
- `customitems.reload` (по умолчанию: op)

## 🎯 Команды API Предметов

### /api-item give

Выдать Java API предмет игроку.

**Синтаксис:**
```
/api-item give <id_предмета> [игрок]
```

**Параметры:**
| Параметр | Обязательный | Описание |
|----------|--------------|----------|
| id_предмета | Да | ID Java API предмета |
| игрок | Нет | Игроку кому выдать (по умолчанию: вы) |

**Примеры:**
```bash
# Выдать API предмет себе
/api-item give fire_sword

# Выдать API предмет другому игроку
/api-item give fire_sword Steve
```

**Права:**
- `customitems.give` (по умолчанию: op)

---

### /api-item list

Показать список всех доступных Java API предметов.

**Синтаксис:**
```
/api-item list
```

**Примеры:**
```bash
# Показать все API предметы
/api-item list
```

**Вывод:**
```
[DC-CustomItems] Java API предметы: fire_sword, teleport_staff
```

**Права:**
- `customitems.list` (по умолчанию: true)

---

### /api-item info

Получить информацию о Java API предмете.

**Синтаксис:**
```
/api-item info <id_предмета>
```

**Параметры:**
| Параметр | Обязательный | Описание |
|----------|--------------|----------|
| id_предмета | Да | ID Java API предмета |

**Примеры:**
```bash
# Получить информацию о предмете
/api-item info fire_sword
```

**Вывод:**
```
[DC-CustomItems] Предмет: fire_sword
[DC-CustomItems] Название: Огненный Меч
[DC-CustomItems] Материал: NETHERITE_SWORD
[DC-CustomItems] Тип: TOOL
```

**Права:**
- `customitems.list` (по умолчанию: true)

## 🔧 Утилитарные Команды

### /ci help

Показать справку по командам.

**Синтаксис:**
```
/ci help
```

**Примеры:**
```bash
# Показать справку
/ci help
```

**Вывод:**
```
[DC-CustomItems] Доступные команды:
[DC-CustomItems] /ci give <предмет> [игрок] - Выдать предмет
[DC-CustomItems] /give list - Список предметов
[DC-CustomItems] /ci reload - Перезагрузить плагин
[DC-CustomItems] /api-item give <id> [игрок] - Выдать API предмет
[DC-CustomItems] /api-item list - Список API предметов
[DC-CustomItems] /api-item info <id> - Информация о предмете
```

**Права:**
- `customitems.list` (по умолчанию: true)

## 🔐 Права

### Права по Умолчанию

| Право | Описание | По умолчанию |
|-------|----------|--------------|
| `customitems.give` | Выдавать предметы | op |
| `customitems.list` | Список предметов | true |
| `customitems.reload` | Перезагрузка плагина | op |
| `customitems.admin` | Админ права | op |

### Права для Предметов

Вы можете настроить кастомные права для каждого предмета:

```yaml
my_sword:
  permission: "myplugin.sword"
```

Игроки должны иметь это право для использования предмета.

## 💡 Советы

### Совет 1: Используйте Автодополнение

Все команды поддерживают автодополнение:
- Напишите `/ci give ` и нажмите Tab
- Напишите `/give list` и нажмите Enter

### Совет 2: Проверяйте Вывод Консоли

После команд проверяйте консоль на:
- Сообщения об успехе
- Сообщения об ошибках
- Предупреждения

### Совет 3: Используйте @ Селекторы

Используйте селекторы Minecraft:
- `@p` - Ближайший игрок
- `@a` - Все игроки
- `@s` - Вы сами

### Совет 4: Узлы Прав

Используйте узлы прав в вашем плагине прав:
- GroupManager
- LuckPerms
- PermissionsEx
