# Начало Работы с DC-CustomItems

## 🎯 Добро Пожаловать!

Это руководство поможет вам создать свой первый кастомный предмет за 5 минут!

---

## 📋 Предварительные Требования

Прежде чем начать, убедитесь что у вас есть:

- ✅ Работающий сервер Minecraft (1.20+)
- ✅ Плагин установлен в папке `plugins/`
- ✅ Сервер перезапущен или выполнен `/ci reload`
- ✅ Права OP или `customitems.give`

---

## 🚀 Шаг 1: Создайте Первый Предмет

### Перейдите в Папку Предметов

Откройте папку сервера и перейдите в:
```
plugins/DC-CustomItems/items/
```

### Создайте Новый Файл

Создайте файл `hello-sword.yml` с таким содержимым:

```yaml
hello_sword:
  item:
    type: DIAMOND_SWORD
    title: '&aПривет Меч'
    glowing: true
  lore:
    - ''
    - '&7Это мой первый кастомный предмет!'
    - ''
  type: TOOL
  activation-slot: HAND
  trigger-actions:
    - 'on_click_right:message:&aПривет от моего меча!'
    - 'on_click_right:particle:HEART:20'
    - 'on_click_right:sound:ENTITY_PLAYER_LEVELUP:1:1'
```

### Сохраните и Перезагрузите

1. Сохраните файл
2. Перейдите в консоль сервера или в игре
3. Напишите: `/ci reload`

Вы должны увидеть:
```
[DC-CustomItems] Загружено 1 кастомных предметов
```

---

## 🎮 Шаг 2: Получите Предмет

Напишите эту команду:
```
/ci give hello_sword
```

### Попробуйте!

1. Возьмите меч в руку
2. Нажмите правую кнопку мыши (ПКМ)
3. Вы должны увидеть:
   - Сообщение: "Привет от моего меча!"
   - Частицы в виде сердечек
   - Звук повышения уровня

---

## 🔧 Шаг 3: Настройте Предмет

Давайте сделаем его интереснее!

### Добавьте Эффекты

```yaml
hello_sword:
  item:
    type: DIAMOND_SWORD
    title: '&6Мощный Меч'
    glowing: true
    unbreakable: true
  lore:
    - ''
    - '&7ПКМ для ускорения!'
    - ''
  type: TOOL
  activation-slot: HAND
  click-cooldown: 3000
  trigger-actions:
    - 'on_click_right:effect:SPEED:10:2'
    - 'on_click_right:effect:STRENGTH:10:1'
    - 'on_click_right:particle:FLAME:50'
    - 'on_click_right:sound:ENTITY_BLAZE_SHOOT:1:1'
    - 'on_click_right:message:&6Сила активирована!'
    - 'on_click_right:title:&6&lМОЩЬ!::&7Скорость и Сила на 10 секунд!'
```

### Перезагрузите и Попробуйте

```
/ci reload
/ci give hello_sword
```

Теперь при ПКМ вы получите скорость и силу!

## 📝 Разбор Конфигурации

Давайте разберем что каждая часть значит.

### Свойства Предмета

```yaml
item:
  type: DIAMOND_SWORD     # Какой материал использовать
  title: '&6Название'     # Отображаемое название (& = код цвета)
  glowing: true           # Эффект свечения чар
  unbreakable: true       # Предмет нельзя сломать
```

### Описание (Lore)

```yaml
lore:
  - ''                   # Пустая строка
  - '&7Описание'         # Серый текст
  - '&eЕще информация'   # Желтый текст
```

### Действия

```yaml
trigger-actions:
  - 'on_event:action'    # Формат: событие:действие
```

---

## 🎨 Основные Действия

### Сообщения

```yaml
- 'on_click_right:message:&aПривет!'
```

### Эффекты

```yaml
- 'on_click_right:effect:SPEED:10:2'
# effect:ТИП:ДЛИТЕЛЬНОСТЬ_СЕК:УРОВЕНЬ
```

### Частицы

```yaml
- 'on_click_right:particle:FLAME:50'
# particle:ТИП:КОЛИЧЕСТВО
```

### Звуки

```yaml
- 'on_click_right:sound:ENTITY_PLAYER_LEVELUP:1:1'
# sound:ТИП:ГРОМКОСТЬ:ТОН
```

### Лечение

```yaml
- 'on_click_right:heal:10'
# heal:КОЛИЧЕСТВО (в полухочках)
```

### Урон

```yaml
- 'on_click_right:damage:5'
# damage:КОЛИЧЕСТВО
```

### Телепортация

```yaml
- 'on_click_right:teleport:100:64:200'
# teleport:X:Y:Z
```

### Заголовки

```yaml
- 'on_click_right:title:Заголовок:Подзаголовок:10:40:10'
# title:ЗАГОЛОВОК:ПОДЗАГОЛОВОК:ПОЯВЛЕНИЕ:ДЕРЖАНИЕ:ИСЧЕЗНОВЕНИЕ
```

## 💡 Советы для Новичков

### Совет 1: Начинайте Просто

Не пытайтесь создать сложные предметы сразу. Начните с:
- Меча с сообщением
- Затем добавьте частицы
- Потом добавьте эффекты
- Развивайтесь постепенно

### Совет 2: Используйте Комментарии

Добавляйте комментарии чтобы помнить что делает каждое действие:

```yaml
my_sword:
  # Основные свойства
  item:
    type: DIAMOND_SWORD
  
  # При ПКМ
  trigger-actions:
    - 'on_click_right:message:Привет!'  # Показать сообщение
    - 'on_click_right:effect:SPEED:5:1'  # Ускорение
```

### Совет 3: Тестируйте Часто

После каждого изменения:
1. Сохраните файл
2. Выполните `/ci reload`
3. Попробуйте предмет

### Совет 4: Проверяйте Консоль

Если что-то не работает, проверьте консоль сервера на ошибки!
