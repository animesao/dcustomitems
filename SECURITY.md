# Security Policy

## Поддерживаемые версии

| Версия | Поддержка |
|--------|-----------|
| 1.325.x | ✅ актуальная |
| < 1.325 | ❌ обновитесь |

## Сообщение об уязвимости

**Не создавай публичный Issue для уязвимостей.** Вместо этого:

1. Используй [Private vulnerability reporting](https://github.com/animesao/dcustomitems/security/advisories/new)
   на GitHub (вкладка Security → Report a vulnerability).
2. Если это невозможно — свяжись с автором напрямую.

В отчёте укажи: версию плагина, шаги воспроизведения, оценку влияния
(что может сделать атакующий), PoC при наличии. Ответ — в течение 72 часов.

## Известные архитектурные особенности

### Runtime-компиляция Java (важно)

Плагин компилирует `.java`-файлы из `plugins/DC-CustomItems/items/` прямо на
сервере (`JavaItemCompiler`). Это **осознанная** возможность исполнения
произвольного кода (RCE by design): функция даёт Java API без пересборки jar.

Следствие: **любой, кто может записать файл в `items/`, получает полный
контроль над сервером** — включая доступ через уязвимости других плагинов,
веб-панелей или file-менеджеров.

Митигация:

- Отключи компиляцию в `config.yml`: `java-compilation: false`
  (YAML-предметы работают без неё).
- Ограничь доступ к папке `plugins/DC-CustomItems/` на уровне ФС/панели.
- Не устанавливай плагины из недоверенных источников, которые пишут в чужие
  папки `plugins/`.

### YAML-предметы и действия `command:`

Действие `command:...` выполняет команды от консоли. YAML-предметы, которые
могут создавать недоверенные пользователи (если у тебя есть такая механика),
могут выполнять любые команды — выдавай право на использование предметов
осознанно (`permission:` в предмете).

## Что мы считаем уязвимостью

- Обход permissions плагина
- Инъекции через конфиги/БД (SQL, YAML deserialization)
- Утечка данных между игроками/мирами
- Крахи (DoS) через специально сформированные конфиги

## Что НЕ считается уязвимостью

- Описанное выше поведение runtime-компиляции (задокументировано, отключаемо)
- Социальная инженерия на админах сервера
- Уязвимости самого Minecraft/Bukkit (репортить в Paper/Spigot)
